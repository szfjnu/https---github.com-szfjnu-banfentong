## 三、使用规范

### 安全区域
Logo主体应保持在中心区域，四周留出至少10%的边距空间。

### 最小尺寸
- 数字媒体：不小于 48px
- 印刷物料：不小于 15mm

### 颜色使用
| 场景 | 推荐方案 |
|------|----------|
| 深色背景 | 方案一（科技霓虹）或方案三（深色芯片） |
| 白色/浅色背景 | 方案二（极简白底） |
| 小程序图标 | 方案四（应用图标） |
| 视频/动画 | 方案一（科技霓虹，带动画效果） |

### 禁止事项
- 不要拉伸变形Logo
- 不要更改品牌色
- 不要添加阴影或描边（除设计自带外）
- 不要在复杂背景上直接使用

## 四、SVG转PNG方法

由于SVG是矢量格式，需要转换为PNG才能在所有场景使用：

### 方法1：在线转换
1. 访问 https://convertio.co/zh/svg-png/ 或 https://cloudconvert.com/svg-to-png
2. 上传SVG文件
3. 选择输出尺寸（建议512x512或1024x1024）
4. 下载PNG

### 方法2：使用Python转换
```bash
pip install cairosvg
```

```python
import cairosvg

# 转换科技霓虹版
cairosvg.svg2png(
    url='banfentong-logo-tech.svg',
    write_to='banfentong-logo-tech.png',
    output_width=1024,
    output_height=1024
)

# 转换应用图标版
cairosvg.svg2png(
    url='banfentong-logo-appicon.svg',
    write_to='banfentong-logo-appicon.png',
    output_width=256,
    output_height=256
)
```

### 方法3：使用设计软件
- Adobe Illustrator：打开SVG → 导出为PNG
- Figma：导入SVG → 导出PNG
- Sketch：导入SVG → 导出PNG

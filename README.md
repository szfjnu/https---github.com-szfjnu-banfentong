# 班级积分管理系统 - 微信小程序

## 项目概述

这是一个功能全面的班级管理微信小程序,采用腾讯云开发作为后端服务,基于25个详细需求文档开发。系统涵盖学生基础信息、积分规则、日常积分、宿舍积分、积分兑换、志愿服务、处分管理、技能证书、学期管理、成绩管理、学生分组、卫生值日、教室座位、AI点评、生日祝福、天气提醒、权限管理、数据可视化、自动化流程、转段考监控、制度文件管理等多个模块,实现对学生成长的全过程管理。

## 技术栈

- **前端**: 微信小程序原生框架 + TDesign设计规范
- **后端**: 腾讯云开发 (云函数 + 云数据库 + 云存储)
- **数据库**: 云开发数据库 (MongoDB)
- **定时任务**: 云函数定时触发器

## 部署说明

### 1. 云开发环境配置

1. 在微信开发者工具中开通云开发
2. 创建云开发环境,记录环境ID
3. 修改 `app.js` 中的云开发环境ID:
```javascript
wx.cloud.init({
  env: 'your-env-id', // 替换为你的云开发环境ID
  traceUser: true,
});
```

### 2. 数据库初始化

1. 在云开发控制台创建数据库集合
2. 根据 `DATABASE_SCHEMA_V2.md` 创建30个数据集合
3. 创建必要的索引
4. 导入初始数据(积分项目、处分基础数据等)

### 3. 云函数部署

需要部署以下云函数:
1. `login` - 用户登录
2. `convertDormScore` - 宿舍积分折算
3. `handleBidAuction` - 积分兑换投标处理
4. `generateAIReview` - AI点评生成
5. `dailyReminder` - 每日定时提醒

部署步骤:
1. 右键点击云函数文件夹
2. 选择"上传并部署:云端安装依赖"
3. 等待部署完成

### 4. 定时任务配置

为 `dailyReminder` 云函数配置定时触发器:
- 每天7:00: 发送值日提醒和天气提醒
- 每天17:00: 检查未完成值日任务
- 每天8:00: 检查并发送生日祝福

配置方法:
1. 在云开发控制台 → 云函数 → dailyReminder
2. 点击"定时触发器" → "添加触发器"
3. 设置触发规则:
   - `0 7 * * * *` - 每天7:00
   - `0 17 * * * *` - 每天17:00
   - `0 8 * * * *` - 每天8:00

### 5. 小程序配置

1. 修改 `project.config.json` 中的 `appid`
2. 在微信公众平台配置服务器域名
3. 配置小程序权限和用户信息获取
4. 配置模板消息权限

## 常见问题

### Q1: 如何配置定时任务?
A: 在云开发控制台 → 云函数 → dailyReminder → 定时触发器,添加触发规则。

### Q2: 如何设置宿舍积分折算比例?
A: 在学期管理中设置 `dorm_conversion_ratio` 字段,默认为0.3(30%)。

### Q3: 如何启用投标模式?
A: 在创建兑换物品时,选择"投标模式",并设置投标开始和截止时间。

### Q4: AI点评如何工作?
A: 系统会自动收集学生的积分、活动、违纪等数据,生成个性化点评内容。

### Q5: 如何发送模板消息?
A: 需要在微信公众平台配置模板消息,并在云函数中调用 `cloud.openapi.subscribeMessage.send` API。
